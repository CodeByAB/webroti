# Säkerhet

Hittar du ett säkerhetsproblem i Web-ROTI: skapa **inte** ett publikt
issue. Använd i stället GitHubs privata rapportering under fliken
_Security → Report a vulnerability_ i repot, eller kontakta
repo-ägaren direkt.

Web-ROTI lagrar inga personuppgifter: bara mötes-koder, röstvärden och
tidsstämplar, som raderas 90 dagar efter senaste aktivitet.
