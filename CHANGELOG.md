## 2.0.0 (2026-11-07)

### Features

- Rewrite Web-ROTI from scratch for Cloudflare Pages, Pages Functions and D1,
  replacing the 2013 Java/Jersey service. Same features: create a meeting,
  vote 1.0–5.0, see count, average and min–max, QR code and direct link.
- Results refresh by themselves, a meeting code can be entered on the start
  page, and the vote link can be copied.
